# Compound Droplet Designer

Source code for a local browser application for core and shell area prediction,
constrained inverse design, and generation frequency optimization.

## Distribution scope

This repository contains software source code, the HTML interface, dependency
requirements and a Windows launcher. Research datasets, fitted model weights,
support observations, validation measurements, figure source tables, simulation
files, and the earlier research release are not distributed here.

This is a source-only distribution. Prediction and inverse design require
separately authorized private model and support resources. They cannot run from
this public checkout alone. No synthetic replacement predictions are provided.

## Installation

Use Python 3.12 to 3.14 and create a virtual environment, then install:

```bash
python -m pip install -r requirements.txt
```

## Running with authorized private resources

Keep the private resource directory outside this repository. It must contain:

```text
private-resources/
  data/
    model_metadata.json
    stable_support.csv
    nonstable_features.csv  (optional)
  models/
    soft_conservation_ann.joblib
```

The files must belong to the matching application/model version. Only load
trusted serialized model files from the authorized resource package.

PowerShell:

```powershell
$env:CDD_PRIVATE_RESOURCES = 'D:\private-resources'
python app/compound_droplet_designer.py
```

Linux or macOS:

```bash
export CDD_PRIVATE_RESOURCES=/path/to/private-resources
python app/compound_droplet_designer.py
```

The program starts a localhost server and opens a browser. Calculations use the
private resources locally. The interface has no research-dataset download tab or
research-dataset download endpoint. Reports generated by the local user remain
available for export.

## Inputs and outputs

Physical inputs are phase inlet velocities, the middle-phase zero-shear dynamic
viscosity and Cross parameters. The program supports physical and dimensionless
input modes. It predicts inner-core and net shell areas and can match both area
targets, maximize the estimated generation frequency or match a requested
frequency. The model and reference geometry determine the applicable domain.
